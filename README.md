# СКСТ — Стройка королевств с Тамарой

Первая статическая версия сайта по сводке проекта от 20 октября 2026 года. Не требует сборки, базы данных или ключей доступа.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Публикация

Файлы `index.html` и `style.css` можно разместить на любом статическом хостинге. Для GitHub Pages после загрузки файлов в GitHub выберите Settings → Pages → Deploy from a branch → main → / (root). Публичный адрес появится в настройках после успешного развёртывания. Публикация из текущей среды ещё не выполнена.

## Контент

Карта, полные названия государств, флаги, правила участия и текст мирного договора требуют оригинальных материалов. Декоративная иллюстрация на главной не является картой СКСТ. Дата новости обозначает дату её подготовки по сводке, а не установленную дату подписания договора.

Шрифты системные, внешние зависимости не нужны.

## Новости

Боковая лента ведёт к восьми газетным статьям. У шести выпусков из новых вложений и магазина-алфавита отсутствуют доступные исходные файлы с EXIF и подтверждённые даты. Они выделены в архив без хронологического порядка. Дата 19.10.2026 у войны — дата подготовки выпуска, не дата события; время неизвестно. Для точной сортировки нужны оригиналы с метаданными либо даты от автора. Изображения из чата пока не включены в файлы сайта.

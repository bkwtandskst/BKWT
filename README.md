# СКСТ — Стройка королевств с Тамарой

Первая статическая версия сайта по сводке проекта от 20 октября 2026 года. Не требует сборки, базы данных или ключей доступа.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

## Публикация

Файлы `index.html` и `style.css` можно разместить на любом статическом хостинге. Для GitHub Pages после загрузки файлов в GitHub выберите Settings → Pages → Deploy from a branch → main → / (root). Публичный адрес появится в настройках после успешного развёртывания. Публикация из текущей среды ещё не выполнена.

## Контент

Карта, полные названия государств, флаги, правила участия и текст мирного договора требуют оригинальных материалов. Декоративная иллюстрация на главной не является картой СКСТ. Дата новости обозначает дату её подготовки по сводке, а не установленную дату подписания договора.

Шрифты системные, внешние зависимости не нужны.

## Планирование игр и общее голосование

`planner.js` подключается к API на том же адресе. GitHub Pages выдаёт только статические файлы: на нём можно открыть форму и циферблат, но общие предложения и голоса недоступны. Локальные голоса не имитируются.

Для полноценной работы запустите весь сайт через Python 3.10+:

```sh
cd /workspace/BKWT
python3 server.py
```

Порт по умолчанию — 8080; его можно изменить переменной `PORT`. SQLite хранится в `.local/polls.sqlite3`. Для хостинга с постоянным диском задайте `SKST_DB` абсолютным путём на этом диске; сохраняйте резервные копии файла. Не используйте временный диск для публичных голосов. Внешние зависимости не нужны. Процессы надо запускать заново после перезапуска среды.

Проверка: GET `/api/options` возвращает JSON; создайте будущий вариант, проголосуйте из двух разных браузеров и проверьте общий счётчик. Даты и время выбираются в МСК (UTC+3). Истёкшие предложения скрываются; новые варианты ограничены годом вперёд. Каждый браузер может поддержать несколько вариантов и снять свой голос; идентификация анонимная по cookie. Это не строгая защита от повторного голосования: другой браузер или очистка cookie создают нового участника. Перед запуском для широкой аудитории нужны ограничения запросов и модерация на хостинге. Не размещайте сервер без HTTPS.

Настройка публичного хостинга пока не выполнена. Сохранение файлов в GitHub не запускает Python-сервер.
